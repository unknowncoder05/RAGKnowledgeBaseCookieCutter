# pm-auth

Shared authentication module for ProjectMaker templates.

Provides JWT authentication, Social Logins, Password Recovery, and an extensible `AbstractPMUser` model.

## Installation

```bash
pip install git+https://github.com/unknowncoder05/pm-auth.git
```

## Dependencies

This package requires `pm-utils` to be installed in the project.

```bash
pip install git+https://github.com/unknowncoder05/pm-utils.git
```
